Интерактивная веб-лаборатория для визуализации математики, теории сигналов и линейных систем. Проект создан как практическое дополнение к семинару по курсу «Радиотехнические цепи и сигналы» и позволяет в реальном времени «крутить ручки» параметров, наблюдая за тем, как оживают математические абстракции.

## 🚀 Возможности

Приложение разделено на три большие группы, повторяющие логику семинара: от базового математического ликбеза до анализа линейных цепей и цифровой фильтрации.

### 1. Векторы и базисы (Математический ликбез)
Эта группа закладывает фундамент: комплексные числа как естественный язык теории цепей, геометрию операций над ними, понятие базиса и ортогональности. Без этого невозможно понять ни спектральный анализ, ни преобразование Лапласа.

*   **Комплексные числа:** Три формы записи одного числа (алгебраическая, тригонометрическая, показательная). Формула Эйлера \(e^{j\varphi} = \cos\varphi + j\sin\varphi\) как мост между геометрией и алгеброй. Интерактивно показывается, что умножение — это поворот с растяжением (модули перемножаются, аргументы складываются).
*   **Сигналы и векторы:** Векторное представление дискретных сигналов. Косинусное сходство и угол между векторами как мера их «похожести». Наглядно видно, почему скалярное произведение — это основа для рядов Фурье.
*   **Смена базиса:** Как координаты одного и того же вектора меняются при повороте системы координат. Демонстрируется, что сам вектор (геометрический объект) остаётся неизменным, а меняется лишь его описание в новом базисе.
*   **Ортогональность:** Матрица Грама для тригонометрической системы функций. Показывается, почему \(\int \cos(mt)\cos(nt)dt = 0\) при \(m \neq n\) и как это свойство позволяет раскладывать сложные сигналы на простые гармоники.
*   **Комплексные фокусы:** Два классических примера, снимающих «страх» перед комплексными числами: корни из отрицательных чисел (\(\sqrt{-9} = \pm 3j\)) и решения уравнения \(\cos x = 2\) в комплексной плоскости.

### 2. Ряды и спектры (Переход к частотной области)
Группа показывает, как периодический сигнал раскладывается в ряд Фурье, как дискретный спектр превращается в непрерывный при устремлении периода к бесконечности, и как цифровое (дискретное) преобразование Фурье связано с непрерывным.

*   **Ряд Фурье:** Аппроксимация меандра частичными суммами. Визуализируются ушки Гиббса — характерные выбросы на разрывах, которые не исчезают с ростом числа гармоник, а лишь сужаются. Столбчатая диаграмма коэффициентов показывает, что амплитуды убывают как \(1/k\).
*   **Комплексный спектр:** Переход от вещественного ряда Фурье (с синусами и косинусами) к комплексным коэффициентам \(`C_k`\). Демонстрируется свойство сопряжённой симметрии \(C_{-k} = \overline{`C_k`}\) для вещественных сигналов.
*   **ДПФ на пальцах:** Дискретное преобразование Фурье через матрицу скалярных произведений. Показывается, что частоты «заворачиваются» по модулю \(N\) (\(k = -2\) эквивалентно \(k = N-2\)), и как это связано с теоремой Котельникова.
*   **Импульсы и sinc:** Спектр периодической последовательности прямоугольных импульсов. Видно, как дискретные гармоники «нанизываются» на огибающую \(\text{sinc}(f\tau)\), и как скважность \(Q = T/\tau\) определяет, какие гармоники попадают в нули.
*   **Одиночный импульс:** Переход от ряда к интегралу Фурье. Численное ДПФ на длинном кадре сравнивается с аналитической формулой \(A\tau \cdot \text{sinc}(f\tau)\). Видно, что при увеличении окна наблюдения дискретные отсчёты всё плотнее заполняют непрерывную кривую.
*   **Базис Котельникова:** Ортогональность сдвинутых sinc-функций \(\phi\_k(t) = \text{sinc}(t - k)\). Интерактивно показывается, что \(\int \phi\_m(t)\phi\_n(t)dt = 0\) при \(m \neq n\) и \(=1\) при \(m=n\), что лежит в основе теоремы отсчётов.
*   **Дельта-функция:** Аппроксимация \(\delta(t)\) сужающимися прямоугольными импульсами единичной площади. Видно, как спектр стремится к константе (равномерный спектр), а фильтрующее свойство \(\int f(t)\delta(t)dt = f(0)\) выполняется всё точнее с уменьшением ширины импульса.

### 3. Системы и цепи (Анализ линейных систем)
Здесь математический аппарат применяется к реальным цепям. Показаны три взаимодополняющих метода анализа: дифференциальные уравнения во временной области, преобразование Лапласа и спектральный анализ. Завершается всё цифровой фильтрацией.

#### 3.1 Цепи и импедансы
*   **Импеданс RLC:** Комплексное сопротивление последовательного RLC-контура как функция частоты. На резонансе \(|Z|\) падает до \(R\) (индуктивное и ёмкостное сопротивления компенсируются), а фаза проходит через ноль. До резонанса цепь ведёт себя как ёмкость, после — как индуктивность.
*   **RC-ФНЧ (1-й порядок):** АЧХ и ФЧХ простейшего фильтра нижних частот. Показывается, что на частоте среза \(|K| = 1/\sqrt{2}\) (−3 дБ), а фаза равна −45°. Переходная характеристика демонстрирует экспоненциальное нарастание с постоянной времени \(\tau = RC\).
*   **RC-делитель (рампа):** Реакция RC-делителя на линейно нарастающий сигнал. Сравниваются численное решение ОДУ и аналитическая формула. Видно, что в установившемся режиме выход отстаёт от входа на постоянную величину (статическая ошибка слежения).

#### 3.2 Динамика и полюса
*   **Механика и Электрика:** Демонстрация изоморфизма между механической колебательной системой (масса-пружина-демпфер) и электрическим RLC-контуром. Одни и те же дифференциальные уравнения описывают обе системы, что позволяет переносить интуицию из одной области в другую.
*   **H(s) и полюса:** Передаточная функция как отношение полиномов. Карта полюсов на комплексной плоскости: вещественная часть определяет затухание, мнимая — частоту колебаний. Диаграммы Боде (АЧХ и ФЧХ) для фильтров разных типов (ФНЧ, ФВЧ, полосовой, режекторный).
*   **Разряд конденсатора:** Три характера переходного процесса в RLC-контуре в зависимости от сопротивления: колебательный (недодемпфированный), критический и апериодический (передемпфированный). Полюса на комплексной плоскости наглядно показывают, как меняется характер затухания.
*   **Вычеты:** Обратное преобразование Лапласа как сумма вычетов в полюсах. Показывается, как каждый полюс даёт свой вклад в сигнал во временной области (экспоненту или затухающую синусоиду), и как их сумма восстанавливает исходный сигнал.
*   **Дельта в H(s):** Случай, когда передаточная функция имеет прямую связь (числитель и знаменатель одного порядка). В импульсной характеристике появляется дельта-функция, что означает мгновенный «проскок» сигнала на выход.

#### 3.3 Свёртка и фильтрация
*   **Интеграл Дюамеля:** Реакция системы как свёртка входного сигнала с импульсной характеристикой. Сравниваются численная свёртка (`np.convolve`) и точное решение ОДУ (`scipy.signal.lsim`). Демонстрируется, что оба метода дают идентичный результат, подтверждая фундаментальную теорему о связи временной и частотной областей.
*   **Три метода:** Один и тот же результат (реакция на рампу) вычисляется тремя способами: аналитически, численным решением ОДУ и через интеграл Дюамеля. График ошибок показывает, что расхождения лежат в пределах погрешности численных методов.
*   **БПФ от h(t):** Численное преобразование Фурье от импульсной характеристики сравнивается с аналитической формулой \(H(j\omega)\). Это визуальное доказательство того, что спектр импульсной характеристики есть частотная характеристика системы.
*   **FFT Blur:** Простейший цифровой фильтр — скользящее среднее. Показывается, как во временной области шум сглаживается, а в частотной — высокочастотные компоненты подавляются. АЧХ фильтра имеет характерные нули, положение которых зависит от ширины окна.
*   **Свёртка vs Спектр:** Демонстрация теоремы о свёртке: линейная свёртка во временной области эквивалентна умножению спектров, но только при отсутствии краевых эффектов (циклическая свёртка через ДПФ требует обнуления краёв или дополнения нулями).

## 🛠 Предварительные требования

Для работы с проектом используется сверхбыстрый менеджер пакетов и окружений **[uv](https://github.com/astral-sh/uv)**. 

Если у вас его нет, установите (выберите команду для своей ОС):

### **macOS (через Homebrew):**
```bash
brew install uv
```

### Linux / macOS (через curl):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Windows (через PowerShell):
```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### Через pip / pipx (кроссплатформенно):
```
pip install uv
```
 или
```
pipx install uv
```

## 🚀 Установка и запуск

### Клонируйте репозиторий и перейдите в папку:
```bash
git clone https://github.com/Nick-Msk/math_visual_lab.git
cd math_visual_lab
```

### Создайте виртуальное окружение и установите зависимости:
(Эта команда автоматически создаст папку .venv и установит все нужные пакеты из pyproject.toml)
```bash
uv sync
```

### Активируйте виртуальное окружение:
Для macOS / Linux:
```bash
source .venv/bin/activate
```

Для Windows:
```
.venv\Scripts\activate
```

### Запустите приложение:
```bash
uv run math-visual-lab
```

(Браузер откроется автоматически по адресу http://127.0.0.1:8050)

Примечание: Благодаря uv приложение можно запускать и без активации виртуального окружения — команда uv run math-visual-lab сама подхватит нужное окружение. Активация (шаг 3) полезна, если вы хотите запускать обычный python, работать в IDE (например, VS Code или PyCharm) или использовать ruff из командной строки.


### 🐳 Запуск через Docker
Если вы не хотите ставить зависимости локально, можно запустить всё в контейнере:

#### Вариант 1: Автоматический скрипт (рекомендуется)

В проекте есть скрипт-обёртка, который сам собирает образ и запускает контейнер:
```bash
uv run docker-start
```

Как выйти: Нажмите Ctrl+C в терминале. Скрипт автоматически остановит и удалит контейнер, чтобы не оставлять мусор.

#### Вариант 2: Ручной запуск

```bash
docker build -t math_visual_lab .
docker run -p 8050:8050 -e DOCKER_ENV=1 math_visual_lab
```

Как выйти: Нажмите Ctrl+C. Чтобы полностью удалить остановленный контейнер, выполните docker rm math_lab.

### Откройте http://localhost:8050 в браузере.

(Переменная -e DOCKER_ENV=1 сообщает приложению, что внутри контейнера нет браузера, и не пытаться его открыть).

Интерактивная веб-лаборатория для визуализации математики, теории сигналов и линейных систем.

Приложение построено на базе **Dash** и **Plotly** и позволяет в реальном времени "крутить ручки" параметров, наблюдая за тем, как оживают математические абстракции.

## 🚀 Возможности

Приложение разделено на три большие группы:

### 1. Векторы и базисы
*   **Комплексные числа:** три формы записи, формула Эйлера, умножение как поворот.
*   **Сигналы и векторы:** косинусное сходство, углы между многомерными сигналами.
*   **Смена базиса:** как меняются координаты вектора при повороте системы координат.
*   **Ортогональность:** матрица Грама для тригонометрического базиса.
*   **Комплексные фокусы:** корни из отрицательных чисел и решения `cos(x) = 2`.

### 2. Ряды и спектры
*   **Ряд Фурье:** аппроксимация меандра и ушки Гиббса.
*   **Комплексный спектр:** симметрия спектра вещественного сигнала.
*   **ДПФ на пальцах:** дискретное преобразование Фурье и алиасинг частот.
*   **Импульсы и sinc:** спектр прямоугольных импульсов и скважность.
*   **Одиночный импульс:** переход от ряда к интегралу Фурье.
*   **Базис Котельникова:** ортогональность sinc-функций.
*   **Дельта-функция:** аппроксимация δ(t) и её фильтрующее свойство.

### 3. Системы и цепи
*   **Цепи:** импеданс RLC, RC-фильтры, делители напряжения.
*   **Динамика и полюса:** ОДУ, преобразование Лапласа, карты полюсов, вычеты.
*   **Свёртка и фильтрация:** интеграл Дюамеля, БПФ импульсной характеристики, цифровая фильтрация (FFT Blur).

## 🛠 Предварительные требования

Для работы с проектом используется сверхбыстрый менеджер пакетов и окружений **[uv](https://github.com/astral-sh/uv)**. 

Если у вас его нет, установите (выберите команду для своей ОС):

### **macOS (через Homebrew):**
```bash
brew install uv```

### Linux / macOS (через curl):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh```

### Windows (через PowerShell):
```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"```

### Через pip / pipx (кроссплатформенно):
```pip install uv```
 или
```pipx install uv```

## 🚀 Установка и запуск

### Клонируйте репозиторий и перейдите в папку:
```bash
git clone https://github.com/Nick-Msk/math_visual_lab.git
cd math_visual_lab```

### Создайте виртуальное окружение и установите зависимости:
(Эта команда автоматически создаст папку .venv и установит все нужные пакеты из pyproject.toml)
```bash
uv sync```

### Активируйте виртуальное окружение:
Для macOS / Linux:
```bash
source .venv/bin/activate```

Для Windows:
```
.venv\Scripts\activate```

### Запустите приложение:
```bash
uv run math-visual-lab```

(Браузер откроется автоматически по адресу http://127.0.0.1:8050)

Примечание: Благодаря uv приложение можно запускать и без активации виртуального окружения — команда uv run math-visual-lab сама подхватит нужное окружение. Активация (шаг 3) полезна, если вы хотите запускать обычный python, работать в IDE (например, VS Code или PyCharm) или использовать ruff из командной строки.


### 🐳 Запуск через Docker
Если вы не хотите ставить зависимости локально, можно запустить всё в контейнере:

#### Вариант 1: Автоматический скрипт (рекомендуется)

В проекте есть скрипт-обёртка, который сам собирает образ и запускает контейнер:
```bash
uv run docker-start```

Как выйти: Нажмите Ctrl+C в терминале. Скрипт автоматически остановит и удалит контейнер, чтобы не оставлять мусор.

#### Вариант 2: Ручной запуск

bash```
docker build -t math_visual_lab .
docker run -p 8050:8050 -e DOCKER_ENV=1 math_visual_lab```

Как выйти: Нажмите Ctrl+C. Чтобы полностью удалить остановленный контейнер, выполните docker rm math_lab.

### Откройте http://localhost:8050 в браузере.

(Переменная -e DOCKER_ENV=1 сообщает приложению, что внутри контейнера нет браузера, и не пытаться его открыть).
